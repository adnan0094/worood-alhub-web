# 🌹 ورود الحب - موقع معرض الورود والطبيعة

موقع ويب متكامل وجميل لعرض صور الورود والطبيعة بتصميم عصري وواجهة سهلة الاستخدام.

## ✨ المميزات

- 🖼️ **معرض صور متكامل** - عرض 12+ صورة جميلة من الورود والطبيعة
- 🎨 **تصنيف الصور** - تصفية الصور حسب الألوان والفئات
- ❤️ **نظام المفضلة** - حفظ الصور المفضلة محلياً
- 📱 **متجاوب** - يعمل بشكل مثالي على جميع الأجهزة
- 🌍 **دعم العربية** - واجهة كاملة باللغة العربية
- 💫 **تأثيرات جميلة** - رسوم متحركة وتأثيرات بصرية
- ⌨️ **اختصارات لوحة المفاتيح** - تحكم سهل بالصور

## 🚀 البدء السريع

### المتطلبات
- متصفح ويب حديث (Chrome, Firefox, Safari, Edge)

### التثبيت والتشغيل

1. استنساخ المستودع:
```bash
git clone https://github.com/adnan0094/worood-alhub-web.git
cd worood-alhub-web
```

2. فتح الملف في المتصفح:
```bash
# على Linux/Mac
open index.html

# على Windows
start index.html
```

أو استخدام خادم محلي:
```bash
python -m http.server 8000
```

ثم زيارة `http://localhost:8000` في المتصفح

## 📖 الاستخدام

### التنقل بين الصور
- **← السابقة** - الذهاب للصورة السابقة
- **التالية →** - الذهاب للصورة التالية
- **🎲 عشوائية** - عرض صورة عشوائية
- **❤️ إضافة** - إضافة الصورة للمفضلة

### اختصارات لوحة المفاتيح
- `←` أو `→` - التنقل بين الصور
- `Space` - صورة عشوائية
- `F` - إضافة/إزالة من المفضلة

### تصفية المعرض
- **الكل** - عرض جميع الصور
- **🔴 حمراء** - ورود حمراء فقط
- **💗 وردية** - ورود وردية فقط
- **⚪ بيضاء** - ورود بيضاء فقط
- **🟡 صفراء** - ورود صفراء فقط
- **🌿 طبيعة** - صور الطبيعة والزهور
